# Rayzta 🚀

**Rayzta** is an ultra-fast, plug-and-play Command Line Interface (CLI) framework designed for Instagram Automation. Built to be a smarter, faster, and more modular alternative to legacy tools like InstaPy.

## 🌟 Features
*   **Modular Architecture**: Everything is a plugin (Search, Chat, Follow, Analyzer, Authorizer, Marker).
*   **Real Instagram API Backend**: Powered by `instagrapi` for fast, headless interactions without relying on slow Selenium browsers.
*   **Smart Analytics**: Generates real-time ASCII sparkline charts of your growth directly in the terminal.
*   **Interactive Terminal UI**: Utilizes `msvcrt` and `rich` for an interactive, gorgeous command-line dashboard and profile gallery.
*   **Automation Engine**: Configurable follow automation with randomized human-like delays (e.g., 5-15 seconds).

## 💻 Installation

```bash
# Clone the repository
git clone https://github.com/rayzien/rayzta.git
cd rayzta

# Install dependencies
pip install -r requirements.txt

# Run the dashboard
python main.py
```
